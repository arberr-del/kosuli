# Kosuli Company Website

A modern company website created for **Kosuli (Кошули)**. The website provides visitors with information about the company, its services, and ways to get in touch through a clean and user-friendly interface.

## Project Overview

This project was developed as a business website for Kosuli. The goal was to create a professional online presence that allows visitors to learn about the company and easily navigate through its main sections.

## Features

- Home page
- About Us page
- Contact page
- Navigation menu
- Responsive layout
- Clean and professional design

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
